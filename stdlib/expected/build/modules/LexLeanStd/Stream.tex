\subsection*{\texttt{appendItems}}
\noindent Kind: \texttt{definition}.\par
\noindent Type parameters: \texttt{(Item)}.\par
\noindent Parameters: \texttt{(left : List (Item)) (right : List (Item))}.\par
\noindent Type: \texttt{List (Item)}.\par
\noindent Definition: \texttt{(match left with | List.nil => right | List.cons item rest => (item :: appendItems (Item) (rest) (right)))}.\par
\noindent Axiom policy: \texttt{none}.\par
